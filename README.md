# Faisal Alshammari - Portfolio Website

## Overview
This is a personal portfolio website built for Faisal Alshammari, an AI & Data Science student. It showcases his skills, projects, experience, and services.

## Technologies Used
- HTML5
- CSS3 (Vanilla, emphasizing Glassmorphism and Dark Mode)
- JavaScript (Vanilla, for interactions and animations)

## How to Run
1. Simply double-click on `index.html` to open it in your default web browser.
2. No installation or server is required (it's a static site).

## Features
- **Responsive Design**: Works on mobile and desktop.
- **Glassmorphism UI**: Modern, sleek aesthetic.
- **Scroll Animations**: Elements reveal as you scroll down.
- **Interactive Cursor**: Subtle glow effect following the mouse.
